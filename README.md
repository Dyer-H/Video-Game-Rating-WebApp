# Video-Game-Rating-WebApp
The purpose of this project is to create a web application that stores video game ratings and displays those ratings to other users. 

# Installation/Usage Instructions
This project is written in Python, and makes use of Flask, Flask-Login, Flask SQL-Alchemy, and Flask-JSON. These dependencies are all included in the attached virtual environment.
Once you have installed the project locally using whichever method you choose, open a Python IDE and click the run button when viewing the final.py script. This project is hosted locally, so at the moment, only you can access the data. You could also choose to run the project via a command line using something like python final.py. Either works.

# Features & Technology Stack
Makes use of Python, HTML, CSS, and Javascript. Python packages used mentioned above. Javascript makes use of AJAX requests to avoid form reloading. This also means that the script hosts some internal APIs.
